# DXN Store - فروشگاه محصولات طبیعی

## 📦 درباره
فروشگاه محصولات بهداشتی، ارایشی و مکمل‌های طبیعی در اربیل کردستان عراق

**صاحب/فروشنده:** Ghazi Argoshi

## 🚀 شروع سریع

### 1. نصب وابستگی‌ها
```bash
npm install
```

### 2. تنظیم دیتابیس
```bash
# PostgreSQL را نصب کنید
# دیتابیسی به نام dxn_store ایجاد کنید

# فایل .env.local رو تنظیم کنید:
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/dxn_store
```

### 3. ایجاد جداول
```bash
npm run db:push
```

### 4. اجرای سایت
```bash
npm run dev
```

سایت بر روی `http://localhost:3000` فعال می‌شود

## 📁 ساختار پروژه

```
src/
├── app/              # صفحات Next.js
├── components/       # کامپوننت‌های React
├── db/              # دیتابیس و Schema
├── store/           # Zustand Store (سبد خرید)
└── lib/             # تابع‌های کمکی
```
