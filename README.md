## 📦 About

**Owner/Seller:** Ghazi Argoshi

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Setup Database
```bash
# Install PostgreSQL
# Create database: dxn_store

# Create .env.local file:
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/dxn_store
```

### 3. Create Tables
```bash
npm run db:push
```

### 4. Run Development Server
```bash
npm run dev
```

Open http://localhost:3000
